# AI PDF Chatbot

An AI-powered PDF chatbot built using Python, Google Gemini, LangChain, ChromaDB, and Gradio.

## Features
- Read and extract text from PDF documents
- Retrieve relevant information using vector search
- Answer questions using Google Gemini
- Interactive chat interface with Gradio
- Handle spelling mistakes in user questions

## Technologies
- Python
- Google Gemini API
- LangChain
- ChromaDB
- Hugging Face Embeddings
- Gradio

## Setup
1. Install Python.
2. Install the required packages from requirements.txt.
3. Set your GOOGLE_API_KEY securely.
4. Run the Jupyter Notebook.

## Security
Never publish your API key or private credentials.
